# SDL3 Odin Bindings

Binding files (read these directly, do not guess APIs):
- Core:  /usr/lib/odin/vendor/sdl3/sdl3_<module>.odin
- Image: /usr/lib/odin/vendor/sdl3/image/sdl_image.odin
- Mixer: /usr/lib/odin/vendor/sdl3/mixer/sdl3_mixer.odin
- TTF:   /usr/lib/odin/vendor/sdl3/ttf/sdl3_ttf.odin
